Bitácora de desarrollo - TiendaExpress (TI3041)

## Actividad 1: Creación del proyecto Django

Rol: Desarrolladora del proyecto.

Tarea: Crear el proyecto Django, configurar el entorno virtual e instalar las dependencias necesarias.

Contexto: Desarrollo del caso TiendaExpress, utilizando Django, la aplicación catalogo y un repositorio en GitHub.

Resultado: Configuré el entorno de trabajo, creé el proyecto y lo vinculé con GitHub para mantener un respaldo del código.

## Actividad 2: Creación y carga de datos

Rol: Desarrolladora del proyecto.

Tarea: Crear los modelos correspondientes a las categorías y productos, y cargar la información en el sistema.

Contexto: Al ejecutar el servidor, inicialmente solo aparecía la página de bienvenida de Django, por lo que tuve que revisar la configuración y realizar la carga de datos.

Resultado: Utilicé el administrador de Django para ingresar y organizar las categorías y los productos de TiendaExpress.

## Actividad 3: Control de versiones con Git

Rol: Responsable del repositorio.

Tarea: Revisar los archivos del proyecto, gestionar los cambios y configurar el archivo .gitignore.

Contexto: Durante la revisión del repositorio identifiqué un problema con el archivo db.sqlite3, que aparecía con un tamaño de 0 bytes en GitHub.

Resultado: Revisé la estructura del proyecto y comprendí la importancia de excluir archivos innecesarios o locales mediante .gitignore.

## Reflexión
Realicé las actividades de desarrollo de manera autónoma, aplicando los conocimientos adquiridos durante las clases. Logré crear y configurar el proyecto Django, trabajar con los modelos, ingresar categorías y productos desde el administrador y utilizar GitHub para gestionar el código. Durante el proceso también tuve que resolver algunos inconvenientes, lo que me permitió comprender mejor el funcionamiento de Django y el control de versiones.
